Crime Intelligence Analytics Dashboard An Excel-based Crime Intelligence Analytics Dashboard designed to analyze crime data and present important insights through interactive KPIs, charts, and filters. Overview This project uses Microsoft Excel to transform raw crime records into a professional and easy-to-understand analytical dashboard. It helps analyze crime patterns based on crime type, severity, location, case status, victim demographics, and time. Key Features
Total Cases – Shows the total number of reported cases.
High / Critical Cases – Displays serious crime cases.
Open & Closed Cases – Provides an overview of case status.
Average Victim Age – Shows the average age of victims.
Crime Type Analysis – Compares different types of crimes.
Crime by Location – Identifies areas with reported crime activity.
Crime by Time Period – Analyzes crime distribution throughout the day.
Daily Crime Trend – Shows changes in crime activity over time.
Interactive Filters/Slicers – Allows users to explore specific portions of the dataset. Tools Used
Microsoft Excel
Excel Tables
Pivot Tables
Pivot Charts
Slicers
Excel Formulas
Data Visualization Dashboard KPIs The dashboard contains five major KPIs: Total Cases | High/Critical | Open Cases | Closed Cases | Average Victim Age These KPIs are dynamically calculated from the underlying CrimeTable.
